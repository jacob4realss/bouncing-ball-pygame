# Character pictures

Put a picture here to replace a drawn character. Name it `<size>_<Name>.png`
(or `.webp`), using the character's short name without accents:

- `1_Mahrez.png`
- `2_Charlemonte.png`
- `3_Mexique.png`
- `4_1xBet.png`
- `5_Choucha.png`

Use a transparent background (a PNG cut-out). The picture is fitted to the
potato's circle, so a roughly round, head-only image works best. Then run
`python -m potato_reel` and `python -m potato_reel.web` again.
